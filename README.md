
# Full Stack Web Application - README

## Overview
This full-stack web application serves both customers and administrators, with secure admin login authentication. Built with Express, HTML, JavaScript, and a Single Page Application (SPA) for a seamless frontend experience, the backend leverages MongoDB for flexible data handling.

### Architecture
The project includes both multi-page rendering and a SPA, allowing for fast initial loads and dynamic, uninterrupted user interactions. MongoDB’s NoSQL structure was chosen for scalability, particularly suited to the app’s dynamic and unstructured data requirements.

### Functionality
JSON enabled efficient data transfer between backend and frontend, serving as the main data format across API endpoints. Refactored reusable UI components, especially on the admin side, kept the code modular and optimized for faster updates.

### Testing
API testing covered all core methods (GET, POST, PUT, DELETE) using tools like Postman. JWT authentication and role-based access were implemented, ensuring secure endpoints for admins only.
